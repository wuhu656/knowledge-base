2. 沟通用幼儿园大班水平：短句、少术语、分步骤、给能直接照抄的命令

- 同步：E:\knowledge-base\sync.ps1（推 GitHub）

- 开 web：E:\knowledge-base\start-web.ps1

## 六、坑记录

- git 全局代理会让 github.com 推送 TLS 失败，已为 github.com 单独绕开代理（.gitconfig 的 [http "https://github.com/"] proxy=）
- PowerShell 5.1 的 .ps1 脚本要 UTF-8 BOM，否则中文注释/字符串解析报错
- flowus 的 markdown put 端点对部分页面 404，写内容改用 block append
